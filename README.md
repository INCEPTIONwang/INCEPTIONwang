# Hi, I'm Xianghui Wang 👋

I'm an M.S. student at **Sichuan University**, working on **computer vision and embodied intelligence**. My research focuses on vision-language-action (VLA) models for robotic manipulation, particularly how to make their execution more efficient and reliable.

[Homepage](https://inceptionwang.github.io/) · [Email](mailto:2024222050105@stu.scu.edu.cn) · [OpenReview](https://openreview.net/profile?id=%7EXianghui_Wang1) · [Hugging Face](https://huggingface.co/INCEPTIONwang)

## Research Interests

- **Vision-Language-Action Models:** connecting visual observations and language instructions to robot actions.
- **Efficient & Reliable Execution:** action chunking, adaptive execution horizons, and feedback-driven replanning.
- **Reinforcement Learning for Robotics:** post-training to extend reliable action chunks and reduce redundant physical steps.
